# 微信透明 GIF 导出与验收

本项目默认使用**正方形、透明背景、循环播放、严格不超过 500,000 字节**作为用户指定的目标。微信表情开放平台的当前规格、静态表情、封面/图标、数量、版权材料要求可能不同；上传前请以平台官方最新页面为准。

## 文本
采用**程序化后期叠字**而非让生成模型在每一帧画字。默认粉红色粗字、白色描边，心形装饰可选；文字整体**固定不动**，不要底板、色条或半透明字幕框；每一帧文字相同。使用用户自己有权使用且覆盖中文的本地字体，不能再发布字体文件。

例：
```sh
python scripts/wechat_export.py raw.gif done.gif --text 哈哈 --font "/path/to/cjk.ttf" --heart
```

若 GIF 已在上游合成过字幕，则省略 `--text` 和 `--heart`。如需不同字幕，在输入目录旁建立 JSON：`{"001":"哈哈","002":"委屈"}`，然后传入 `--captions`。

## 压缩与验收
脚本依次调整画布尺寸、抽帧步长、调色板色数，保持动画总播放时长和无限循环。某些复杂 GIF 无法在目标体积内保留足够的帧数；此时**抛错，不交付假合格 GIF**。降帧后重新检查运动连贯性，避免人物跳帧。出现色带、笔触锯齿、细线消失、字幕过小或形象退化，应回头简化原动画或重新画关键帧。

技术检查仅核对可解码、方形、循环、体积和时长。上传微信前依然必须人工确认文字无错、字幕位置、角色一致性、循环接缝和平台最新官方限制。
