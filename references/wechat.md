# 方形 GIF 导出与平台适配

本项目默认生成**正方形、循环播放的 GIF，单文件大小不超过 500000 字节**，适合用作即时通讯表情包的初始导出目标；这不意味着所有平台采用相同的官方限制。真实平台上传前请核对当期规则。

## 输入与角色

角色来自用户提供或获授权的图片。人物、宠物、卡通、像素、手绘、黏土、照片等都支持；背景透明与否应以素材及平台要求为准。真正逐帧动画必须先提供内容不同且连续的姿势帧，不能用整张图的整体移动、缩放或摇摆冒充完整表演。

## 字幕

**后期统一叠字**，避免图像模型在每一帧画汉字。默认自动分析风格，选择清晰的大字、对比色或对应画面的艺术字体；支持 `classic`、`cute`、`heritage`、`brush`。字幕在整个 GIF 内保持固定坐标，无背景板、字幕条或半透明矩形；如用户明确要求无字，则不叠加字幕。

```sh
python scripts/wechat_export.py source.gif result.gif \
  --text "好的" --font "/path/to/licensed-CJK-font.ttf"
```

批量使用 `--captions captions.json` 为不同 GIF 提供对应文本，`--zip` 打包。书法样式需要额外的 `--brush-font`，所有字体必须是合法可用的本地文件；不随项目分发。

## 导出和验收

程序可通过画布尺寸、帧取样、GIF 调色板调整体积；处理后重新检查方形尺寸、循环、总时长和文件大小。逐帧角色表演的导出必须保留不少于12帧（原始计划默认16帧），不能压到只剩静态感。

GIF 的透明边缘、文字描边、色带、角色一致性、动作自然程度、首尾循环接缝和实际平台审核仍需人工确认。压缩失败应明确报错，不要交付超限文件或谎称已通过平台验收。
