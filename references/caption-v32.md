# 通用字幕设计系统

字幕需要适合**本次输入的角色和画面**，而不是继承某位使用者的历史喜好。程序读取部分动作帧，依据透明度、亮度、色彩和饱和度选择配色与布局；其判断是启发式，**不能替代设计师的语义理解与视觉审查**。

| 样式 | 适合的画面 | 文字设计 |
| --- | --- | --- |
| `auto`（默认） | 各类输入 | 自动判断；整段 GIF 内不改变颜色和坐标 |
| `classic` | 高对比摄影、复杂实景背景 | 暖白粗字、深色外轮廓 |
| `cute` | 清新、柔和、多彩 Q 版角色 | 明亮字色、清晰内外描边 |
| `heritage` | 暖色调插画与复古手绘 | 米金与深棕的协调对比 |
| `brush` | 留白充足、浅色水墨或纸张插画 | 墨色书法题字、无厚边/底框 |

## 使用

单张 GIF：

```sh
python scripts/wechat_export.py input.gif output.gif \
  --text "收到" --font "/path/to/licensed-CJK-font.ttf" \
  --caption-style auto
```

整套按批次制作：

```sh
python scripts/studio_v3.py build workspaces/demo/production.json \
  --font "/path/to/licensed-CJK-font.ttf"
```

当用户明确指定风格时可用 `--caption-style classic|cute|heritage|brush`；对于书法样式需另提供 `--brush-font` 和合法可用的书法字体。不应假设任何人物、宠物、职业、文化背景都必然对应特定字幕风格。

同一角色的整套 GIF 会锁定首次选择的字幕样式；单张 GIF 的所有帧也固定字幕位置，不逐帧重新检测。不同角色可采用不同字体风格，角色之间不强制统一。

## 质量标准

字体应有足够字重或独立笔锋，缩小到聊天窗口仍能辨识；尽量与角色构图融合，不在人物眼睛、脸、手势等关键区域放置文字。禁止文字底色条、矩形字幕板、不必要的动画漂移；图像生成阶段应尽量不绘制文字，统一在后期叠加。复杂背景、过长文案、字体缺字和压缩导致的细线损失都需要人工审核。

`auto` 无法充分理解文化含义、角色个性、构图叙事；如果用户反馈不协调，应针对本次作品调整字体、字号与位置，不把这一调整永久写成所有用户的偏好。
