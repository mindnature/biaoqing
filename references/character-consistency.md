# 角色身份锁定与逐帧表演规范

## 身份锚点
为每个新角色在 `character.json`（用户可自行创建）记录：轮廓、头身比、脸型、眼间距、鼻口关系、主色/配色、耳朵与头发/帽子、衣物结构及标志物；同时明确可变表情、可变动作和禁改项。

任何用户提供或获授权的角色形象，都应以用户**实际提供并确认的参考图**为准，不得凭角色名自行猜测或拿网络上同名人物替代。

## 动作分镜
- 收到：注意/听 → 正面确认 → 点头或敬礼 → 回位。
- 哈哈：微笑 → 开怀大笑 → 身体前仰/后仰 → 收势。
- 委屈：忍耐 → 皱眉垂头 → 泪光/眼泪 → 擦泪回位。
- 哼：转头、抱臂、鼓腮，身体重心配合而不是仅动嘴。
- 早安/晚安：明确问候、打招呼或困倦动作，不应只是文字替换。

逐帧之间保持角色中心点与镜头固定。应有动作运动的分段节奏，而非全程等速循环。若体量或角度改变，应在相邻帧解释运动连续性。

## 视觉验收
1. 首先检查 3–4 张关键姿势；检查通过后才补足动作。新生成动作可能变脸或长出多余肢体。
2. 逐格放大查看眉眼、手指、衣服、头部边缘、所有小配饰的连贯性。
3. 动画实际播放及首尾跨帧衔接；发现跳帧先补中间动作，切勿只增加 FPS 或复制同帧。
4. 检查固定字幕与循环里的每一帧一致，不能出现错字、乱码、双重字幕或者忽大忽小。
5. 评估结果分为：技术通过、助手视觉审查、用户确认，绝不合并为单一「成功」。
