# 思然 GIF Studio V2.0：动作制作与质量控制

本版真正新增的是**可执行的动作分镜计划、逐帧图像数据检查、显式帧替换/位置校正、从 16 张 PNG 到微信 GIF/ZIP 的批处理**，并未打包生成式图像模型。由 Codex/智能体调用自身可用且获授权的图像生成能力，根据文本分镜生成每张姿势；工具不能独立凭一张角色图生出真正的肢体表演。

## 1. 建立角色任务

将你有权使用的角色图片放在工作区，示例为私有路径（不要提交仓库）。

~~~sh
python scripts/studio_v2.py plan \
  --character "一然" --reference "private/yiran.png" \
  --actions "哈哈,委屈,收到,哼,嗯？,晚安,早安,加油,拜拜" \
  --appearance illustration --output workspaces/yiran
~~~

输出：
- \`workspaces/yiran/production.json\`：每个动作的独立文件名、16 帧时序、角色特征
- \`workspaces/yiran/prompts/*.txt\`：图像生成提示词；**角色外观以用户实际提供的参考图为准**
- \`workspaces/yiran/frames/<action>/\`：放置动作 PNG 的空目录

每张 GIF 的帧命名必须是 \`000.png\`～\`015.png\`，均为**同尺寸、同固定视角、具有真实透明像素**的单独角色姿势。不要把 16 格图集当作 16 张文件；必须先按格准确分离。不得靠简单全图上下移动伪装肢体动作，也不得从其他角色素材偷换脸。

先审核 0、5、8、15 四张身份锚点姿势，满意再补齐中间姿势，必须保持连续表演和镜头坐标。

## 2. 在合成之前进行质量检查

~~~sh
python scripts/studio_v2.py inspect workspaces/yiran/frames/received \
  --report workspaces/yiran/received-review.json
~~~

能检测：空白帧、无透明留白/疑似裁切、全帧重复无动作、异常位置跳跃、前景面积突变、平均颜色突变、首尾坐标跳跃。

说明：
- \`blocked\`：客观技术错误；不应继续打包
- \`review_required\`：可能需要人工检查；动作幅度大也可能触发，不应直接当成错误
- \`technical_pass\`：基础检查通过；**不代表角色造型和动作自然**
- 无法仅凭数值可靠判定手指数量、五官是否变形或是否表达出了文案的情绪，必须继续逐帧观看

## 3. 定点修复，禁止糊弄

新建 \`workspaces/yiran/corrections.json\`，为不合格的帧写入显式修正：

~~~json
{
  "5": {"replace": "replacement_005.png"},
  "8": {"shift": [3, -2]}
}
~~~

其中 \`replace\` 指向审核过的正确单帧，路径相对于该修正文件；\`shift\` 只修正明确的整体位置偏差，并检查不会把角色裁切到画布外。

~~~sh
python scripts/studio_v2.py repair \
  workspaces/yiran/frames/received workspaces/yiran/corrections.json \
  workspaces/yiran/fixed-received
~~~

输出**新目录**和 \`repair-log.json\`，不覆盖原始素材。检查新目录后再将通过审核的 PNG 替换到原动作目录。该脚本不自动重绘错误手部/脸部；这类修复仍要调用图像生成工具重画。

## 4. 一键合成已准备好的连续动作

~~~sh
python scripts/studio_v2.py build workspaces/yiran/production.json \
  --font "/path/to/authorized-chinese-font.ttf" --heart
~~~

输出：
- \`build/atlases/*.png\`：一致格尺寸动作图集
- \`build/raw/*.gif\`：原始高清逐帧动作（无字幕）
- \`build/wechat/*.gif\`：统一固定中文字幕 + 小于等于 500000 字节的 GIF
- \`build/reports/*.json\`、\`*-contact.png\`：逐帧风险报告、审核联系表
- \`build/wechat-pack.zip\` 与 \`build/summary.json\`：整套成品和生成记录

\`--strict\` 使任何风险提示都阻止打包。默认只阻止基础技术错误，保留人工审核标记。后期压缩会减小尺寸或减少帧数，可能影响流畅度，成品仍需视觉复核，**自动生成/通过测试均不代表微信审核通过或用户已验收**。

## 5. 限制

1. V2 动作指导是结构化分镜，不是本地 AI 图像/视频模型，实际逐帧姿势由支持图像能力的智能体或创作者生成。
2. 一致性算法是启发式检查，主要看透明轮廓、位置、尺寸和颜色；**尚不能自动识别或修复人脸、手部语义错误**。
3. 不支持用一张 PNG 复制 16 次冒充动作，亦不自动生成中间插帧。
4. 默认微信体积目标 500000 字节；最终发布标准以平台官方当期规定为准。
5. 版权/形象/字体只使用用户自有或获授权素材。仓库的 \`workspaces/\` 被忽略，避免意外公开私有角色照片。
