# 艺术文字与书法字体：可选风格，不是所有角色的默认

通用表情包可以使用粗圆字、手写字、书法字、像素字或简洁无衬线字体，应以本次参考角色、画面留白、文案长度和使用场景决定。

## 书法模式（brush）

适合有充分留白的水墨、淡彩纸张、绘画题字场景。默认使用深墨色、较克制的字重与左上角留白排版；避免厚重描边、光效、白色边框或字幕底板。若主要内容位于左上角，则应由执行智能体人工复核并调整布局，不能以该默认位置遮住主体。

书法质感取决于**实际具有相应笔画的、有合法使用权的字体文件**。黑体改色或倾斜不等于行草书法。本仓库不分发字体，不提供毛笔笔画生成模型。

```sh
python scripts/wechat_export.py raw.gif result.gif \
  --text "加油" \
  --font "/path/to/licensed-CJK-font.ttf" \
  --brush-font "/path/to/licensed-calligraphy.ttf" \
  --caption-style brush
```

程序可能依据浅米色纸张和留白自动挑选 `brush`，也可能误判背景。没有合适书法字体时应选择可用的非书法样式，并清楚说明差别；如果用户明确要求书法，不得假装普通黑体能实现。

## 其他样式

`classic` 注重复杂画面中的可读性；`cute` 注重萌系视觉；`heritage` 可用于色彩克制的插画，但它们也都**只是候选样式**，不是把照片、动物或某个文化主题机械映射到同一种字体。

验收时检查：文字是否完整、无错字、没有双重字幕、不会截断、不会遮住眼睛及手势、缩略图是否清晰、整套 IP 是否统一。用户明确指定字体或排版应优先采用，只要符合法律和输出规格。
