# V3.3｜东方书法题字与艺术字体审美

## 用户认可的视觉基准

示例为「小玄游·开心！」：米白纸张、淡彩手绘人物、浓淡相宜的毛笔字「开心！」置于左上角，似画家题款，人物脸和眼睛完全露出。最美的是**字形**与**画面关系**，不是在机械粗体字外面叠厚重描边。

这张用户图片仅用于判断审美，不作为仓库素材。所有成品必须使用用户有权使用的角色图、书法字体和原画资源。

## 必须区分的四种字幕

| 风格 | 字体/颜色/位置 | 适用 |
| --- | --- | --- |
| brush | 正宗中文毛笔/行书类字体，深墨色，左上角留白，不加厚边、白色外轮廓或底板 | 米白宣纸、低饱和东方水墨手绘、国风画册 |
| heritage | 米金粗字、墨色厚描边，整合式下部排版 | 传统主题 Q 版角色，背景不具明显纸张题字空间 |
| classic | 暖白粗字、深棕厚描边 | 写实猫咪、照片等有实体背景的表情 |
| cute | 粉色粗字、白色内描边和深莓边框 | 软萌彩色 IP、粉彩插画 |

自动识别由像素分析完成，判断「高覆盖的浅米纸色、低饱和、淡彩背景」时选择 brush；不依赖云端模型，也不是语义理解。若自动判断不符，允许 \`--caption-style brush|heritage|classic|cute\` 明确覆盖。

## 排版原则

1. brush 默认题在左上留白处，笔画疏密起伏，字长以 2–4 字为佳。它是**画面题字**不是画面外独立底部标签。
2. 要有提按、笔锋、书写速度和墨色变化的字形。普通黑体换成黑色、旋转角度、添加噪点，**不等于真正的书法字体**。
3. 禁止底色条、彩色板、矩形半透明字幕框、强烈立体描边，避免遮挡眼睛、发髻或手势。纸张题字不必须额外加爱心。
4. 同一套 16 个 GIF 应保持一致的题字风格与固定位置，文字不能每帧漂移或变形；人物动作是独立的 16 帧表演。
5. 如果文字较长，先根据字宽缩小至留白区域，不得覆盖人物脸或碰到画框。若无法同时兼顾，换排版或人工复核。
6. 文字必须写对，优先使用可验证完整汉字的字体；不要让图像模型直接每帧画字。

## 字体文件与技术限制

本项目**不附带、不分发字体文件**。使用 \`--brush-font\` 传入有权合法使用、包含所需汉字的毛笔或行书字体。没有时停止并提示，不得自动换普通黑体冒充。若艺术家拥有手写字透明 PNG，也可以由执行智能体通过受控图层统一叠加，但当前仓库内置的书法文字程序使用字体文件渲染，不具备笔画级毛笔书写生成器。

本模块没有训练视觉模型，只根据纸色和透明度启发式选择书法题字风格；画面实际美感需人工审查。若源角色画面保持真实纸张背景，V3 的严格透明动作帧约束需要另行规划底图合成，不能随意把不透明纸张当作透明 PNG 混入逐帧素材。

## 用法

\`\`\`sh
python scripts/wechat_export.py raw.gif result.gif --text "开心！" \
  --font "/path/to/Chinese-font.ttf" \
  --brush-font "/path/to/licensed-Chinese-calligraphy.ttf" \
  --caption-style auto

# 用户确认书法题字时强制选择 brush
python scripts/wechat_export.py raw.gif result.gif --text "开心！" \
  --font "/path/to/Chinese-font.ttf" \
  --brush-font "/path/to/licensed-Chinese-calligraphy.ttf" \
  --caption-style brush

# 整套表情包自动决定并锁定样式，4个一批
python scripts/studio_v3.py build workspaces/xuanyou/production.json \
  --font "/path/to/Chinese-font.ttf" \
  --brush-font "/path/to/licensed-Chinese-calligraphy.ttf"
\`\`\`

先做一张题字样品，观察缩略图是否足够清晰、书写味道是否到位、是否在左上留白、不遮挡主角，再扩大批量。
