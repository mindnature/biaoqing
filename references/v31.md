# 思然 GIF Studio V3.1｜默认 16 表情、每表情 16 帧、每批 4 张

## 设计决策

- **默认一套**：16 个独立 GIF，固定默认词库按照聊天高频程度排列；每 GIF 16 张独立透明 PNG 动作帧（默认 140ms/帧），计划总计 256 帧。
- **每批制作 4 个**：每批 64 张动作帧，四批顺序独立生产、质量检查、导出，允许阶段性交付；最后一批不足四张时只处理实际数量。
- **用户优先**：明确指定词语时准确制作指定词语；指定数量时按数量从扩展词库取前 N 个。推荐预设 1/4/8/16/24/32；实际 API 支持 1–32，且自定义词语去重。
- **真正动作优先**：每个动作要有眼神、脸部、肩膀、手臂、身体重心的协同变化；不允许把一张图用缩放、平移、摇摆伪装成连续逐帧动作。
- **角色由用户授权**：参考图及其衍生作品在本地 \`workspaces/\`，不把原始素材提交到公共 GitHub。

## 运行命令

~~~sh
# 默认16张，4批
python scripts/studio_v3.py plan --character "一然" --reference "private/yiran.png" --output workspaces/yiran

# 自定义指定文案：数量=给出的词语数量
python scripts/studio_v3.py plan --character "一然" --reference "private/yiran.png" \
  --actions "好的,收到,谢谢,点赞" --output workspaces/yiran-small

# 指定预设数量，不指定具体文案时从默认词库依次扩展
python scripts/studio_v3.py plan --character "一然" --reference "private/yiran.png" \
  --count 24 --output workspaces/yiran-24

# 智能体先按 prompts/*.txt 和 batches/batch-01.md 制作第一批4个表情，
# 每个目录应含 000.png...015.png 共16张不同的角色动作帧。
# 每个动作先单独通过：
python scripts/studio_v3.py inspect workspaces/yiran/frames/okay

# 下一批自动选择第一个尚未技术完成的批次：
python scripts/studio_v3.py build workspaces/yiran/production.json \
  --font "/path/to/authorized-chinese-font.ttf" --heart

# 查询进度
python scripts/studio_v3.py status workspaces/yiran/production.json

# 已有完整素材时按顺序一次执行所有批次
python scripts/studio_v3.py build workspaces/yiran/production.json \
  --font "/path/to/authorized-chinese-font.ttf" --all

# 在全部批次通过后可手动重组完整包
python scripts/studio_v3.py assemble workspaces/yiran/production.json
~~~

注意：\`plan\` 只生成**制作说明**和空文件夹，不能当作已经制作了 GIF。图像生成能力需要由 Codex 或其他具备图像功能的执行环境提供。

## 输出结构

- \`production.json\`：角色身份锚点、默认或自定义数量、分组数、总帧数、动作分镜。
- \`prompts/*.txt\`：一条表情一个逐帧动作提示词。
- \`batches/batch-01.md\` 至 \`batch-04.md\`：各批生产指令及 4 个动作名称；同时保存 JSON 便于机器读取。
- \`frames/<slug>/000.png ... 015.png\`：原始关键帧，均为用户或图像模型制作的不同姿势，不是由计划器自动创造。
- \`build/batch-01/wechat/*.gif\`：一批四个 GIF；\`wechat-pack.zip\`：该批独立压缩包；\`v3-summary.json\`：技术验收状态。
- \`build/complete-pack.zip\`：必须全部批次完成且 GIF 技术验证通过后才生成的完整包；\`complete-manifest.json\`：全套记录。

技术指标还不能完全判断动作的自然程度、五官和手指是否连续；必须使用实际播放和人工逐帧审查。所有表情默认 500000 字节上限，压缩后至少保留 12 帧，不能以降低到轻微抖动冒充真正逐帧表演。微信正式发布要求以平台当期官方标准为准。
